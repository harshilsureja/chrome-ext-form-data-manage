# Changelog

## 1.0.0 — 2026-10-12

First public release.

- Profile autofill with smart field matching (autocomplete, name, id, label, placeholder) and custom fields.
- Auto-generate realistic test data — offline generator or randomuser.me by nationality.
- Save filled forms with their URL; replay in the current tab or a new tab.
- Optional auto-fill when a saved form's URL opens.
- History of submitted, saved, filled, captured and generated forms with search and filters.
- Per-tab Chrome side panel built with React and shadcn/ui; light and dark themes.
- Export / import all data as JSON.
