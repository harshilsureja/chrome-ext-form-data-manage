# Contributing to Open Autofill

Thanks for helping out! Bug reports, ideas and pull requests are all welcome.

## Getting started

```bash
git clone https://github.com/harshilsureja/open-autofill.git
cd open-autofill
npm install
npm run dev
```

Load the `dist/` folder via **chrome://extensions → Developer mode → Load unpacked**. `npm run dev` rebuilds on save; click the reload icon on the extension card to pick up changes.

## Where things live

- **`public/content.js`** — runs on web pages: reads fields, fills them, autofills the profile, generates random data. Plain JavaScript (no bundler), so keep it dependency-free.
- **`public/background.js`** — service worker: per-tab side panel and history writes.
- **`public/faker.js`** — offline random data, shared by the page script and the panel.
- **`src/`** — the React + shadcn/ui side panel. UI primitives are in `src/components/ui` (generated by the shadcn CLI).

## Pull requests

1. Fork and create a branch: `git checkout -b fix/short-description`.
2. Keep changes focused; match the surrounding code style.
3. Run `npm run build` — it must pass type-checking.
4. Test the change in Chrome on at least one real form.
5. Describe what changed and how you tested it. Screenshots help for UI changes.

## Reporting bugs

Please include the page URL (or a minimal HTML form that reproduces it), what you expected, and what happened. Check the side panel's console (right-click the panel → **Inspect**) for errors.
