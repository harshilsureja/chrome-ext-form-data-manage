Features

Everything a form needs.
Nothing it doesn't.

Profile autofill

Store your details once. It matches fields by autocomplete, name, id, label and placeholder.

Realistic test data

One click fills every field with a believable person. Use the offline generator or randomuser.me by nationality.

Save & replay

Save a filled form with its URL. Hit Fill later — the extension navigates there and restores every value.

Auto-fill on load

Flip a switch and a saved form fills itself whenever that page opens. Perfect for repetitive QA flows.

Full history

Every submit, save, fill and generation is logged. Search values, filter by action, re-fill or save any entry.

Per-tab side panel

Opens in Chrome's native side panel, only on the tab you clicked. No popups that vanish when you click away.

Framework friendly

Uses native value setters and dispatches real events, so React, Vue, Angular and Svelte forms pick up every change.

Private by design

All data lives in chrome.storage.local. Passwords, hidden and file inputs are never captured.

Screens

A side panel that feels native.

Built with React and shadcn/ui. Light and dark themes included.

How to use

Four steps. Zero retyping.

  1. 01

    Open the panel

    Click the extension icon in the toolbar. The side panel opens for that tab only. Pin the icon for quick access.

  2. 02

    Fill — your way

    Press Autofill profile to use your saved details, or Auto-generate for fresh, realistic test data.

  3. 03

    Save the form

    Happy with the values? Click Save form, give it a name, and optionally enable auto-fill for that URL.

  4. 04

    Replay anytime

    From Saved or History, hit Fill. It opens the URL if needed and restores every field.

Install

Up and running in a minute.

Pick a prebuilt release, or build it yourself from source.

  1. Download open-autofill-vX.Y.Z.zip from the latest release and unzip it.
  2. Open chrome://extensions and switch on Developer mode (top-right).
  3. Click Load unpacked and select the unzipped folder.
  4. Pin the extension from the puzzle-piece menu, then click it on any page.
bash
$git clone https://github.com/harshilsureja/open-autofill.git
$cd open-autofill
$npm install
$npm run build
✓ built in 1.2s → dist/

Then open chrome://extensions, enable Developer mode, click Load unpacked and choose the dist/ folder. Use npm run dev to rebuild on save.

FAQ

Questions, answered.

Is any of my data sent to a server?

No. Profiles, saved forms and history live in chrome.storage.local on your machine. The only network request is the optional randomuser.me data source, which sends nothing about you.

Does it store passwords?

Never. Password, hidden and file inputs are skipped when capturing and filling.

Why does it need access to all sites?

To read and fill forms on whatever page you open the panel on, and to auto-fill saved forms when their URL loads. The extension only acts when you click or when you enabled auto-fill for a URL.

Which browsers are supported?

Any Chromium browser with side panel support (Chrome 116+, Edge, Brave, Arc, Opera).

Does it work with React / Vue / Angular forms?

Yes. Values are set through native setters and real input/change events are dispatched, so controlled components update correctly.

How do I back up or move my data?

Settings → Export JSON. Import the file on another machine with Import JSON — entries are merged, not overwritten.
